# PlainMemo 2.2.0

## New features

- Added collapsible pinned memos. Pin and unpin from a memo's More menu, choose the maximum pinned count in settings, and collapse the pinned section when it is not needed.
- Pinned memo state is stored in plugin data instead of Markdown files. Pinned notes stay available during progressive loading and keep their normal place in the timeline when the pinned section is collapsed.

## Improvements

- Legacy files with leading YAML frontmatter now keep that metadata unchanged while PlainMemo hides it from cards and the editor. New PlainMemo notes remain clean Markdown without YAML.
- Long-card collapse now measures visible content: frontmatter counts as zero, a text line counts as one, and each consecutive blank-line group counts as 0.33.
- Made the mobile editor toolbar more compact. All six tools are visible together; the cancel and send controls are aligned with the toolbar and use matching heights.
- Improved pinned-section spacing and the mobile floating collapse control.

## Fixes

- Fixed mobile cancel and save controls triggering on touch-down. They now run after a normal completed tap.
- Fixed a closing-animation flash for long mobile edits by freezing the editor's size while the keyboard is dismissed.
- Removed obsolete touch deduplication code left over from the previous touch-down save behavior.

## 新功能

- 新增可折叠的置顶笔记区域：可在笔记的更多菜单中置顶或取消置顶，并可在设置中限制置顶数量。
- 置顶状态保存在插件数据中，不写入 Markdown 文件；渐进加载时优先读取置顶笔记，折叠置顶区域后笔记会回到普通时间线中。

## 改进

- 兼容文件开头已有 YAML frontmatter 的旧笔记：PlainMemo 会在卡片和编辑器中隐藏它，保存时原样保留；新建笔记仍保持无 YAML 的干净 Markdown。
- 长卡片折叠改为依据可见正文计算：frontmatter 计 0，文字行计 1，连续空行整体计 0.33。
- 紧凑手机端编辑工具栏，六个工具可同时显示；取消编辑与发送按钮和工具栏统一高度、居中对齐。
- 优化置顶区域的卡片间距，以及手机端悬浮收起按钮的行为。

## 修复

- 修复手机端取消编辑和提交按钮在手指刚按下时就触发的问题，现改为完成一次正常点击后才执行。
- 修复长笔记退出手机编辑时，键盘收起期间编辑面板会短暂撑满整屏的闪烁问题。
- 清理旧的按下提交防重复逻辑，避免留下无效代码。
