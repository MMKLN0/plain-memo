# PlainMemo 2.1.0

## New features

- Added a folder-level Markdown import action that appends creation-time suffixes to compatible files so PlainMemo can recognize them, while preserving file contents and letting Obsidian update links.
- Added Flomo HTML and ZIP import. Each memo becomes a standalone Markdown file with its original content, timestamp, tags, web links, and optional attachments.
- Added Flomo import controls for skipping audio attachments by default and optionally skipping image attachments, plus duplicate detection and attachment reuse.

## Improvements

- Kept desktop editing limited to one memo at a time. Opening another memo now saves the active edit first and switches only after a successful save.
- Mobile toolbar actions now run only after a completed tap, preventing drag gestures from accidentally inserting tags, links, lists, images, or Time buoy markers.
- Recognized tag previews are cleared immediately after creating or editing a memo.
- Stabilized the Flomo import sheet on mobile without interfering with Obsidian's native closing animation.
- On mobile, tapping outside an existing memo editor now saves and closes it. The Back button first dismisses the keyboard, then saves and closes the composer on the next press. Failed saves keep the editor open.

## Fixes

- Fixed complete tags at the end of an existing memo consuming the first Enter key press on mobile.
- Fixed an editor state leak that prevented reopening the same memo after dismissing its mobile editor from the backdrop.
- Fixed mobile tool buttons activating during drag gestures.
- Fixed stale recognized-tag previews remaining after submission.

## 新功能

- 新增文件夹级 Markdown 导入操作：为现有文件补充创建时间后缀，使其能够被 PlainMemo 识别，同时保留文件正文，并由 Obsidian 更新相关链接。
- 新增 Flomo HTML 和 ZIP 导入：每条笔记会转换为独立 Markdown 文件，并保留原始正文、时间、标签、网页链接以及可选附件。
- 新增 Flomo 导入选项：默认跳过音频附件，可选跳过图片附件，并支持重复检测和附件复用。

## 改进

- 电脑端保持同一时间只编辑一条笔记；打开另一条笔记时会先保存当前修改，只有保存成功后才切换。
- 手机端工具栏操作只在完整点击后执行，拖动手势不会再误插入标签、链接、列表、图片或时光浮标。
- 新建或编辑笔记完成后，会立即清除已识别标签的预览。
- 修正手机端 Flomo 导入窗口的闪烁，同时保留 Obsidian 原生的关闭动画。
- 手机端编辑已有笔记时，点击编辑器外部会保存并退出；按返回键时，第一次收起键盘，第二次保存并退出。保存失败时编辑器会保持打开。

## 修复

- 修复已有笔记以完整标签结尾时，手机端第一次回车被标签补全吞掉的问题。
- 修复点击手机编辑器外部关闭后，残留编辑状态导致同一条笔记无法再次打开的问题。
- 修复手机端拖动工具按钮仍会触发操作的问题。
- 修复提交后已识别标签预览没有立即清空的问题。
