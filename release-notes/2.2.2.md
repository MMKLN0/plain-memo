# PlainMemo 2.2.2

PlainMemo 2.2.2 reorganizes synchronized plugin data, adds managed image storage and image paste/drop workflows, and improves multi-device refresh behavior. This release does not automatically migrate settings or pinned memos from 2.2.1. Read the upgrade guide below before updating.

## New features

- Added the `PlainMemo` data layout. PlainMemo now creates `PlainMemo/data` and `PlainMemo/picture` under the Obsidian Vault root while continuing to store memo content as standalone Markdown files.
- Moved scan folders, the default memo folder, collapse threshold, pin limit, trash retention, and Time buoy setting to `PlainMemo/data/settings.json` so memo-related settings can synchronize with the Vault.
- Stored each pin in a separate file under `PlainMemo/data/pins`, reducing conflicts when multiple devices pin different memos before synchronization.
- Added managed image storage under `PlainMemo/picture`. Images inserted by PlainMemo and imported Flomo images use this directory.
- Added desktop image paste and drag-and-drop, plus mobile clipboard image paste.
- Added automatic PlainMemo trash cleanup with a configurable retention period. The default is 30 days.

## Improvements

- Increased the default pinned memo limit from 3 to 5.
- Allowed synchronized pin records to temporarily exceed the configured limit. The limit is enforced only when a user tries to pin another memo, with a unified notice showing the limit and current count.
- Kept pinned-section expansion state and device layout preferences local to each device while synchronizing memo-related settings.
- Retained unpin markers for 15 days so an offline device cannot immediately restore a pin that another device removed; expired markers are cleaned automatically.
- Preserved existing image attachments outside `PlainMemo/picture`. Automatic cleanup only manages images created inside PlainMemo's managed picture directory.

## Fixes

- Fixed PlainMemo failing to initialize after Android restarts until the plugin was manually disabled and re-enabled.
- Fixed synchronized memos and images not appearing immediately on mobile. PlainMemo now retries after synchronized file contents and image bytes have settled and invalidates failed image resources without requiring an Obsidian restart.
- Fixed pinned memo state not refreshing promptly after synchronization on desktop and mobile.
- Fixed editing pinned memos on desktop using the new-memo composer instead of the card editor.
- Fixed Android Back leaving the editor while also triggering Obsidian's "press again to exit" behavior.
- Fixed the floating collapse control after opening or resizing Obsidian's right sidebar, including its horizontal placement and bottom clearance.
- Fixed managed images being written to the Vault root and not being removed after their deleted memo left PlainMemo trash.

## Upgrade guide from 2.2.1

PlainMemo 2.2.2 changes where settings and pin state are stored. Markdown memos are not modified or deleted, but settings and pinned memos from 2.2.1 are not migrated automatically.

### Before upgrading

1. Back up the entire Obsidian Vault.
2. Temporarily disable automatic PlainMemo updates in BRAT on every device.
3. Choose one computer as the primary device. Close Obsidian or disable PlainMemo on the other devices until migration and synchronization finish on the primary device.

### Upgrade the primary device

1. Uninstall the old PlainMemo version and confirm that the old `.obsidian/plugins/plain-memo` directory has been removed. Keep all Markdown memos and any images or attachments they reference.
2. Install and enable PlainMemo 2.2.2. The plugin automatically creates `PlainMemo`, `PlainMemo/data`, and `PlainMemo/picture`; `PlainMemo` is already the default scan and save folder.
3. Optionally move old Markdown memos into `PlainMemo` using Obsidian's file explorer. This keeps the directory tidy and lets Obsidian maintain internal links. Moving is not required: old folders can remain in place and be added with PlainMemo's **Add folder** setting.
4. Configure scan folders, the new-memo folder, collapse threshold, pin limit, trash retention, and Time buoy; then pin the memos that should remain pinned.
5. Wait for the primary device's files and settings to finish synchronizing before continuing on other devices.

### Upgrade other devices

1. After primary-device synchronization finishes, uninstall the old PlainMemo version and confirm that its old plugin directory has been removed.
2. Install and enable PlainMemo 2.2.2, then wait for the synchronized memos, settings, and pin state. Do not move the memos or repeat the pin migration on each device.
3. After every device works normally, re-enable BRAT automatic updates.

PlainMemo 2.2.2 重新组织了同步数据，新增受管图片存储及图片粘贴、拖入功能，并改善多设备同步后的自动刷新。本版本不会自动迁移 2.2.1 的设置和置顶状态，更新前请先阅读下面的升级说明。

## 新功能

- 新增 `PlainMemo` 数据目录结构。插件会在 Obsidian 库根目录下创建 `PlainMemo/data` 和 `PlainMemo/picture`，笔记正文仍然以独立 Markdown 文件保存。
- 将扫描笔记文件夹、新建笔记文件夹、折叠阈值、置顶上限、回收站保留时间和时光浮标设置保存到 `PlainMemo/data/settings.json`，让笔记相关设置可以随 Obsidian 库同步。
- 每条置顶状态分别保存到 `PlainMemo/data/pins`，降低多台设备分别置顶不同笔记后发生同步覆盖的风险。
- 新增 `PlainMemo/picture` 受管图片目录。PlainMemo 插入的图片和导入的 Flomo 图片统一保存到这里。
- 支持电脑端粘贴图片、拖入图片文件，以及手机端从剪贴板粘贴图片。
- 新增 PlainMemo 回收站自动清理，可设置保留时间，默认为 30 天。

## 改进

- 置顶笔记数量上限默认值从 3 调整为 5。
- 多设备同步产生的置顶记录可以暂时超过上限；只有继续置顶新笔记时才会阻止操作，并统一显示上限与当前数量。
- 置顶区展开状态和设备界面布局继续由每台设备独立保存，笔记相关设置则参与同步。
- 取消置顶记录保留 15 天，避免离线设备同步后立即恢复已经取消的置顶；过期记录会自动清理。
- 保留 `PlainMemo/picture` 之外的已有图片附件。自动清理只管理 PlainMemo 自己创建在受管图片目录中的图片。

## 修复

- 修复安卓划掉 Obsidian 后重新打开时 PlainMemo 无法初始化，必须手动停用并重新启用插件的问题。
- 修复手机端同步到的新笔记和图片不能立即显示的问题。同步文件写入稳定后会自动重试，图片加载失败状态也会失效重建，不再需要重启 Obsidian。
- 修复电脑端和手机端同步后置顶状态不能及时刷新的问题。
- 修复电脑端编辑置顶笔记时错误使用新建笔记输入框的问题。
- 修复手机端按返回键退出编辑时同时触发 Obsidian“再次点击退出”的问题。
- 修复打开或调整 Obsidian 右侧栏后，长笔记悬浮收起按钮定位错误的问题，包括横向位置和底部停靠间距。
- 修复受管图片被写入 Obsidian 库根目录，以及笔记从 PlainMemo 回收站删除后图片没有一并清理的问题。

## 从 2.2.1 升级

PlainMemo 2.2.2 调整了设置和置顶数据的保存位置。Markdown 笔记不会被修改或删除，但 2.2.1 的设置和置顶状态不会自动迁移。

### 升级前

1. 备份整个 Obsidian 库。
2. 在所有设备中暂时关闭 BRAT 的 PlainMemo 自动更新。
3. 选择一台电脑作为主设备。其他设备暂时关闭 Obsidian，或者停用 PlainMemo，等待主设备完成迁移和同步。

### 主设备升级

1. 卸载旧版 PlainMemo，并确认旧的 `.obsidian/plugins/plain-memo` 目录已经删除。保留所有 Markdown 笔记，以及笔记正在引用的图片和其他附件。
2. 安装并启用 PlainMemo 2.2.2。插件会自动创建 `PlainMemo`、`PlainMemo/data` 和 `PlainMemo/picture`；`PlainMemo` 已经是默认扫描文件夹和新建笔记文件夹，不需要手动添加。
3. 可以使用 Obsidian 文件管理器，把旧版 Markdown 笔记移动到 `PlainMemo`。这样目录更加集中整洁，Obsidian 也会维护内部链接。迁移不是必须操作：旧笔记可以保留在原文件夹，再通过 PlainMemo 的“添加文件夹”功能加入扫描范围。
4. 重新设置扫描笔记文件夹、新建笔记文件夹、折叠阈值、置顶上限、回收站保留时间和时光浮标，并重新置顶需要置顶的笔记。
5. 确认主设备的文件和设置已经全部同步完成，再继续操作其他设备。

### 其他设备升级

1. 主设备同步完成后，卸载旧版 PlainMemo，并确认旧插件目录已经删除。
2. 安装并启用 PlainMemo 2.2.2，等待同步过来的笔记、设置和置顶状态；不要再次迁移笔记或重复置顶。
3. 确认所有设备正常后，重新开启 BRAT 自动更新。
